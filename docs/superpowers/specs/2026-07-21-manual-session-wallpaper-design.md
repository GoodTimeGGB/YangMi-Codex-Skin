# 杨幂 Codex 手动会话壁纸皮肤设计规格

## 目标

将杨幂皮肤改为每个 Codex 会话由用户主动启用。皮肤不得注册任何 Windows 登录或系统启动持久化，并且“白衣林间”图片必须以电脑壁纸方式呈现在右侧工作区内。

## 启动模型

- 带主题的手动启动器是启用皮肤的唯一入口。
- 应用主题时不得创建或更新计划任务、HKCU `Run` 值或任何其他 Windows 启动项。
- Codex 未运行时，启动器可以使用仅监听回环地址的 CDP 端口启动 Codex。
- Codex 已运行但没有 CDP 时，只有用户明确点击启动器后才允许重启 Codex。任何后台进程都不得接管刚启动的 Codex。
- 会话 watcher 可以在当前 Codex 会话中维持渲染器注入，但不得通过 Windows 登录项跨会话存活，也不得自行启动、停止或重启 Codex。
- 用户关闭 Codex 后必须保持关闭。再次启用皮肤只能重新点击主题启动器。

## 状态与清理

- 手动应用只记录安全清理当前会话所需的渲染器、注入器、watcher、端口和 Codex 身份信息。
- 验证程序必须把计划任务和 HKCU `Run` 两种启动后端均不存在视为正确状态。
- 恢复程序只能停止经过完整身份校验的皮肤进程并移除当前渲染层；若存在可验证的旧版自启注册或孤立的 `watcher-launch.ps1`，也应一并删除。
- 历史 `identity-mismatch` 归档只作为诊断证据保留，不得依据其中的信息终止进程。

## 壁纸视觉

- 保留现有双节点渲染边界：`ym-veil` 与 `ym-portrait`。
- 右侧工作区使用“白衣林间”图片作为壁纸，采用 `background-size: cover`、右侧居中定位且不重复。
- 图片从主工作区中部附近开始并铺满右侧，不覆盖左侧导航栏。
- 只在壁纸左边缘使用窄渐变，使图片自然融入阅读区；不得再添加覆盖整个窗口的粉色或白色蒙层。
- 原生正文、编辑器、工具面板和控件必须位于装饰层之上并保持完全可交互。
- 装饰节点必须保持 `aria-hidden="true"` 和 `pointer-events: none`。

## 失败处理

- 找不到真实 Codex 外壳或无法确认精确的回环 CDP 身份时，操作必须失败，不得注册持久化，并保证 Codex 仍可正常使用。
- 应用失败时，只回滚本次用户明确操作创建的状态和进程。
- watcher 锁不得无限期阻止后续手动恢复或应用；会话 watcher 只执行有界协调，绝不进入 Codex 接管逻辑。
- 普通应用和验证流程不再以“计划任务查询成功”为前提，因此计划任务 API 故障不得阻塞正常皮肤会话。

## 验证要求

- 契约测试证明 apply 不包含任何自启安装器调用。
- watcher 契约测试证明后台代码不会停止或启动 Codex。
- verifier 契约测试要求计划任务和 HKCU `Run` 两种启动后端都不存在。
- 现有 CDP 所有权、渲染器精确性、图片校验、进程身份和回滚测试必须继续通过。
- 实机验证只确认当前手动会话；未经主题启动器的普通 Codex 启动必须保持原样并可正常启动。

## 范围外事项

不得修改 WindowsApps、`app.asar`、应用签名、认证、线程、宠物、插件、Windows 安全设置或任何 Codex 应用文件。
