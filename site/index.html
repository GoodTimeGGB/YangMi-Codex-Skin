FOR NEW CODERS

没用过 AI 也能拥有杨幂皮肤和宠物

不需要会写代码。只要先安装 Codex，再下载这个项目，按你的电脑系统完成下面几步。

Windows

  1. 还没有 Codex？先下载安装 Codex 桌面端并登录。
  2. 下载项目压缩包，解压后不要移动里面的文件夹。
  3. 双击 pet-package/windows/Install-杨幂绿蜂宠物.cmd 安装宠物。
  4. 打开 skin-package/windows/，双击喜欢的 Apply-*.cmd 换上皮肤。
  5. 重启 Codex，在设置中选择杨幂绿蜂宠物。

macOS

  1. 还没有 Codex？先下载安装 Codex 桌面端并登录。
  2. 下载项目压缩包并解压。

打开“终端”，进入项目根目录后复制执行：

zsh pet-package/macos/install-yangmi-green-bee-pet.zsh
zsh skin-package/macos/apply-yang-mi-skin.zsh woodland-white --restart-existing

重启 Codex，在设置中选择杨幂绿蜂宠物。

更多杨幂皮肤制作中WorkBuddy、TraeWork 正在适配。完成后会在这里同步发布。
