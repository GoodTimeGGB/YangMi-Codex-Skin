# 杨幂 Codex 皮肤项目复盘文章设计稿

## 目标

编写一篇中文博客文章，将杨幂 Codex 皮肤项目讲述为一段完整的个人制作经历，同时提供可复用的操作指南。读者应能理解项目缘起、安全安装已发布的皮肤包、替换背景图，以及自定义宠物的制作与安装方式。

## 面向读者

- 希望拥有个性化 Codex 桌面体验的普通用户。
- 想了解安全、可恢复的本地皮肤实现方式的开发者。
- 希望基于本项目制作新主题或新动画宠物的贡献者。

## 叙事主线

文章从“希望把每天使用的编码界面变成自己的工作空间”切入，按实际制作顺序展开：视觉主题构建、动画宠物制作、真实的集成问题，以及最终形成可复用皮肤包的过程。每一段制作故事后都附上读者可直接复现的操作步骤。

## 文章结构

1. 封面图与项目概要。
2. 为什么要给 Codex 做一套自己的皮肤。
3. 皮肤制作：四套主题、非交互式背景层与可替换自定义背景。
4. 宠物制作：参考人物图、动画状态、精灵图校验与安装。
5. 调试复盘：重复注入器、宠物悬浮窗误注入背景、监控器身份校验，以及真实 JPEG 与仅改后缀的 WebP 文件。
6. 用户使用指南：环境要求、一键应用主题、切换主题、替换背景图和恢复默认外观。
7. 仓库目录、参与贡献说明，以及 GitHub、Gitee、GitCode 链接占位。

## 配图规划

- 封面：皮肤与宠物同时展示的最终 Codex 工作区截图。
- 主题对比：四套主题的效果对比图。
- 宠物流程：最终联系表或任选一段动画预览图。
- 调试对比：修复前后宠物悬浮窗的对比图。
- 用户路径：`下载 -> 可选替换背景 -> 双击 Apply -> 验证` 流程图。

图片以仓库相对路径的占位形式引用，使博客正文和仓库 README 可以共用同一份 Markdown。

## 技术表述边界

- 皮肤通过仅限回环地址的 CDP 端点注入，不修改 `WindowsApps` 或 `app.asar`。
- Windows 启动器支持四个主题 ID，并且监控器只维护用户手动建立的当前 Codex 会话。
- `assets/custom-background/background.jpg` 会覆盖当前主题的背景图；文件内容必须是真实 JPEG，不能只是将 WebP 或 PNG 改为 `.jpg` 后缀。
- 自定义宠物通过精灵图和 `pet.json` 单独打包，皮肤注入器不会改动宠物资源。
- 注入器只处理 Codex 主工作区，并会移除独立 `avatar-overlay` 宠物悬浮窗中的皮肤层。
