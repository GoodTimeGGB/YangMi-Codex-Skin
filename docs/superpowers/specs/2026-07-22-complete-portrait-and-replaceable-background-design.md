# 完整人物背景与可替换图片设计

## 目标

将杨幂图片作为右侧工作区的淡化背景完整显示，不裁切；宠物位置不显示人物背景；用户能通过覆盖一个固定文件替换背景图。

## 布局

- 左侧导航保持主题纯色且不显示图片。
- 右侧工作区的 `ym-portrait` 从左栏边界开始，使用 `background-size: contain` 和 `background-position: center`。图片始终保持完整比例，比例不匹配产生的空间使用主题浅色填充。
- 图片以降低的饱和度、亮度提高和约 30–40% 不透明度作为背景，原生控件继续置于其上并可交互。
- 宠物精灵不修改：当前 `yangmi-green-bee/spritesheet.webp` 已验证为带 alpha 通道的 RGBA 文件。为避免人物背景从透明宠物背后透出，壁纸层在右下宠物区域使用主题表面色建立一个非交互净空区。

## 替换图片

- 在技能包内创建 `assets/custom-background/background.jpg`，以现有白衣林间图片作为初始内容。
- `buildPayload` 优先读取该固定文件；文件存在时用于四个主题的背景，文件不存在时回退到主题自身的 `hero` 文件。
- 用户只需将任意 JPEG 图片覆盖为同名 `background.jpg`，然后手动运行一次主题启动器即可重新读取图片；不需要编辑脚本、主题 JSON 或重启 Codex。
- 保持现有图片尺寸和数据 URL 校验；不支持任意路径、URL 或自动扫描目录。

## 验证

- 渲染载荷测试断言右侧图片使用 `contain`，不含 `cover`，并包含宠物净空区。
- 自定义背景存在时载荷使用该文件；缺失时回退到主题图片。
- 继续断言只有两个非交互装饰节点、宠物资源未被修改、CDP 仅使用本地回环端点。
- 皮肤包与安装目录分别运行完整测试集；刷新主题后再运行实时 `--verify`。
