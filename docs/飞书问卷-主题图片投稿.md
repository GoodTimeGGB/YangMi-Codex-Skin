# YangMi Codex Skin 主题图片投稿

在飞书问卷新建表单后，使用以下内容。

## 标题

YangMi Codex Skin 主题图片投稿

## 说明

欢迎蜜蜂投稿适合 Codex 皮肤使用的高清主题图片。优先横屏 JPEG；请附上正式出处或授权说明，便于准确标注和决定是否收录。

## 题目

1. 图片链接或附件
   - 类型：附件
   - 必填：是
   - 提示：请上传高清 JPEG，优先横屏。
2. 图片正式出处
   - 类型：单行文本
   - 必填：是
   - 提示：请填写活动、剧集、海报、摄影作品或原始发布链接。
3. 是否允许在 YangMi Codex Skin 项目中展示和使用
   - 类型：单选
   - 必填：是
   - 选项：允许；仅供审核，不公开；需要先联系我。
4. 投稿人署名或社交账号
   - 类型：单行文本
   - 必填：否
5. 其他补充说明
   - 类型：多行文本
   - 必填：否
