GET STARTED

Download once, choose your system

Install and sign in to Codex first. Download and unzip this project, then keep its folder structure unchanged.

Windows

  1. Download the release ZIP and unzip it.
  2. Run pet-package/windows/Install-杨幂绿蜂宠物.cmd.
  3. Open skin-package/windows/ and run an Apply-*.cmd file.
  4. Restart Codex and select Yang Mi Green Bee in Settings → Pets.

macOS

  1. Download the release ZIP and unzip it.
  2. Open Terminal in the project root.
zsh pet-package/macos/install-yangmi-green-bee-pet.zsh
zsh skin-package/macos/apply-yang-mi-skin.zsh woodland-white --restart-existing

Restart Codex, then select the pet in Settings → Pets.
